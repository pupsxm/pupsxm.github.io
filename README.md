# NEXUS — Digital Studio

Адаптивный сайт цифровой студии на React, Vite, Redux Toolkit и React Router.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который выведет Vite (обычно `http://localhost:5173`).

## Публикация на GitHub Pages

1. Загрузи содержимое этой папки в корень своего публичного репозитория GitHub.
2. В репозитории открой **Settings → Pages**.
3. В разделе **Build and deployment** выбери **Source: GitHub Actions**.
4. Убедись, что основная ветка называется `main`.
5. Открой вкладку **Actions** и дождись успешного выполнения workflow `Deploy NEXUS to GitHub Pages`.
6. Ссылка на опубликованный сайт появится в **Settings → Pages**.

При каждом push в `main` сайт будет пересобираться и публиковаться автоматически.
Vite сам определяет имя репозитория в GitHub Actions и выставляет правильный URL-префикс для GitHub Pages.

## Видео в Hero

Положи файлы в `public/media/`:
- `hero.mp4` — короткое фоновое видео (MP4/H.264, желательно оптимизированное и небольшого размера);
- `hero-poster.jpg` — изображение-заставку, показываемое до загрузки видео.

Видео запускается без звука, автоматически и в цикле. Если файла нет, останется градиентная подложка.

## Контактная форма

Создай локальный файл `.env` на основе `.env.example` и укажи URL сервиса:

```env
VITE_FORM_ENDPOINT=https://your-form-service-endpoint
```

Не добавляй `.env` в Git: он исключён через `.gitignore`. Переменные `VITE_` встраиваются в клиентскую сборку и не подходят для хранения секретных ключей.

В текущем шаблоне отправка выполняется `fetch` методом POST с JSON. Перед публикацией проверь, что выбранный сервис принимает такой формат. Если сервис ожидает `FormData` или поля с другой структурой, адаптируй `src/features/contact/contactSlice.js`.

- Выпадающее меню для desktop и mobile
- Слайдер проектов
